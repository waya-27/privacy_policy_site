Article 2 (Service Overview)

AtomQ is an educational application for learning chemical bonds through an intuitive puzzle-style experience. Key features include:

  • Sandbox Mode: Freely place and bond atoms following valence rules to build molecular structures. Molecule names are displayed when a structure matches the built-in dictionary.
  • Quiz Mode: Build the correct molecular structure to match a displayed target molecule name. Features IUPAC name partial-highlight synchronization.
