Article 2 (Service Overview)

This App provides brain-training games targeting specific brain regions. Key features include:

  • Elevator Calculation (Frontal Lobe): A mental arithmetic game designed to train logical and calculation abilities. Perform multiplication and division as an elevator travels up and down.
  • N-back (Hippocampus): A working memory training game where you compare the current stimulus to the one presented N steps back, training the hippocampus’s memory consolidation function.
  • Target Number (Temporal Lobe): A calculation training game where you combine number cards to reach a target number within a time limit, exercising language and numerical processing abilities.
  • Daily Challenge: A daily challenge mode where you complete all three training games each day, with selectable difficulty levels.
  • Achievement System: Tracks your progress and accomplishments across all training modes.
